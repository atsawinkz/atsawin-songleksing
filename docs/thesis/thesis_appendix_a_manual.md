# ภาคผนวก ก
## คู่มือการใช้งานระบบแชทบอทวินิจฉัยโรคข้าวและแนะนำวิธีการรักษา ผ่านแอปพลิเคชันไลน์

---

คู่มือการใช้งานระบบแชทบอทวินิจฉัยโรคข้าวและแนะนำวิธีการรักษา แบ่งออกเป็น 2 ส่วน ได้แก่:
1. **ส่วนสำหรับเกษตรกรและผู้ใช้งานทั่วไป:** การใช้งานแชทบอทผ่าน LINE Official Account (@325wtzzd)
2. **ส่วนสำหรับผู้ดูแลระบบ (Admin):** การดูแลระบบเวิร์กโฟลว์ (n8n) และฐานข้อมูลความรู้ (Pinecone)

---

### ก.1 ส่วนสำหรับเกษตรกรและผู้ใช้งานทั่วไป

#### ก.1.1 การเพิ่มเพื่อนและเริ่มต้นใช้งานแชทบอท
ผู้ใช้สามารถเริ่มต้นใช้งานได้โดยการสแกนคิวอาร์โค้ด (QR Code) หรือค้นหาด้วย LINE ID: **`@325wtzzd`** เมื่อกดเพิ่มเพื่อน บอทจะส่งข้อความทักทายต้อนรับ และแสดงแถบเมนูด้านล่างของหน้าจอแชท

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-1 หน้าจอเมื่อเพิ่มเพื่อนและเริ่มต้นใช้งานแชทบอท
(คำอธิบายรูป: ภาพหน้าจอแอปพลิเคชัน LINE เมื่อเพิ่มเพื่อนสำเร็จ มีข้อความต้อนรับและแถบเมนูขึ้นที่ด้านล่าง)
```

---

#### ก.1.2 การใช้งานแถบเมนูด้านล่าง (Rich Menu)
แถบเมนูด้านล่างหน้าจอแชท มี 3 ปุ่มให้กดใช้งาน ได้แก่ 1) ถ่ายภาพตรวจโรคข้าว 2) ส่งภาพตรวจโรคข้าว และ 3) วิธีใช้งานแชทบอท เพื่อให้ผู้ใช้กดใช้งานได้อย่างสะดวก

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-2 หน้าจอแถบเมนูด้านล่าง (Rich Menu) ของห้องแชท LINE
(คำอธิบายรูป: ภาพหน้าจอแสดงแถบเมนูด้านล่าง 3 ปุ่ม: ถ่ายภาพตรวจโรคข้าว, ส่งภาพตรวจโรคข้าว และวิธีใช้งานแชทบอท)
```

---

#### ก.1.3 การส่งรูปภาพใบข้าวเพื่อตรวจโรค
ผู้ใช้สามารถกดปุ่ม “ถ่ายภาพตรวจโรคข้าว” เพื่อถ่ายรูปใบข้าวจากกล้อง หรือกด “ส่งภาพตรวจโรคข้าว” เพื่อเลือกรูปจากมือถือ แล้วกดส่งเข้ามาในแชทเพื่อให้บอทตรวจหาโรค

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-3 การเลือกและส่งรูปภาพใบข้าวเข้าห้องแชท LINE
(คำอธิบายรูป: ภาพหน้าจอขณะผู้ใช้เลือกรูปใบข้าวที่มีอาการของโรค แล้วกดส่งเข้ามาในห้องแชท)
```

---

#### ก.1.4 ผลการตรวจโรคและคำแนะนำการรักษา
เมื่อบอทตรวจเสร็จ จะส่งข้อความบอกชื่อโรคข้าวที่พบ เปอร์เซ็นต์ความมั่นใจ และวิธีดูแลรักษาตามคำแนะนำของกรมการข้าวกลับมาให้ทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-4 ผลการตรวจโรคข้าวและคำแนะนำการรักษาที่บอทตอบกลับ
(คำอธิบายรูป: ภาพหน้าจอข้อความผลลัพธ์ที่แชทบอทส่งกลับมา แสดงชื่อโรค เปอร์เซ็นต์ความมั่นใจ และวิธีรักษาโรคข้าว)
```

---

#### ก.1.5 การพิมพ์ถามข้อมูลโรคข้าวเพิ่มเติม
ผู้ใช้สามารถพิมพ์ถามเรื่องโรคข้าวหรือวิธีรักษาเข้ามาในแชทได้โดยตรง เช่น *"โรคไหม้ข้าวรักษายังไง"* บอทจะค้นหาข้อมูลและตอบคำแนะนำที่ถูกต้องกลับมาให้ทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-5 การพิมพ์ถามเรื่องโรคข้าวและคำตอบจากบอท
(คำอธิบายรูป: ภาพหน้าจอขณะผู้ใช้พิมพ์ถามเกี่ยวกับโรคข้าว และแชทบอทตอบคำแนะนำการรักษากลับมา)
```

---

#### ก.1.6 การแจ้งเตือนเมื่อรูปภาพไม่ถูกต้องหรือไม่ชัดเจน
ถ้าผู้ใช้ส่งรูปที่ไม่ใช่ใบข้าว หรือภาพมองไม่เห็นรอยโรค บอทจะแจ้งเตือนให้ถ่ายรูปใบข้าวที่มีรอยโรคให้ชัดเจนในระยะใกล้ แล้วส่งเข้ามาใหม่อีกครั้ง

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-6 ข้อความแจ้งเตือนเมื่อรูปภาพไม่ถูกต้องหรือไม่ชัดเจน
(คำอธิบายรูป: ภาพหน้าจอแสดงข้อความแจ้งเตือนของบอท เมื่อผู้ใช้ส่งภาพอื่นที่ไม่ใช่ใบข้าว หรือภาพมองไม่เห็นรอยโรค)
```
