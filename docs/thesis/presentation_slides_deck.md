## สไลด์ที่ 3

### ขอบเขตด้านระบบและการทำงาน (System Function)

* **การวิเคราะห์รูปภาพ (Image Analysis)**
  * ใช้โมเดล RT-DETR (Real-Time DEtection TRansformer) ในการตรวจจับ (Detection) และจำแนก (Classification) ลักษณะรอยโรคที่ปรากฏบนใบข้าว
* **ระบบค้นหาข้อมูล (RAG System)**
  * ระบบใช้เทคนิค Retrieval-Augmented Generation (RAG) เชื่อมต่อกับ Vector Database เพื่อค้นหาข้อมูลยาและการรักษาจากเอกสารคู่มือวิชาการที่เชื่อถือได้
* **ระบบสนทนา (Conversational Agent)**
  * ใช้ Large Language Model (LLM) ในการประมวลผลภาษาธรรมชาติและเรียบเรียงคำตอบให้เข้าใจง่ายสำหรับเกษตรกร

* **🎙️ Script ผู้บรรยาย:**
  > *"ด้านระบบและการทำงานแบ่งเป็น 3 ส่วนหลักครับ ส่วนแรกคือการวิเคราะห์รูปภาพ ใช้โมเดล RT-DETR ในการตรวจจับตำแหน่งและระบุชนิดของรอยโรคบนใบข้าว ส่วนที่สองคือระบบค้นหาข้อมูล ใช้เทคนิค RAG เชื่อมต่อกับ Vector Database เพื่อค้นหาข้อมูลยาและวิธีรักษาจากคู่มือวิชาการ และส่วนที่สามคือระบบสนทนา ใช้ LLM ช่วยเรียบเรียงคำตอบให้ออกมาเป็นภาษาที่อ่านง่ายและเข้าใจได้ทันทีสำหรับเกษตรกรครับ"*

## สไลด์ที่ 6

### ภาพรวมการทำงานของระบบ

* **ขั้นตอนการทำงานของระบบ :**
  1. เกษตรกรส่งรูปใบข้าวผ่าน LINE OA
  2. n8n คัดแยกข้อความและรูปภาพไปยัง AI Server
  3. โมเดล RT-DETR-L ตรวจจับรอยโรค (ได้ชื่อโรค + ความมั่นใจ)
  4. RAG ค้นหาข้อมูลยาและคู่มือวิชาการ
  5. Gemini 2.5 Flash เรียบเรียงคำตอบให้อ่านง่าย
  6. ส่งการ์ด Flex Message กลับเข้าแชท LINE

* **🎙️ Script ผู้บรรยาย:**
  > *"สไลด์นี้แสดงขั้นตอนการทำงานของระบบครับ เริ่มจากเกษตรกรส่งรูปใบข้าวเข้ามาทาง LINE OA ตัว n8n จะรับภาพและส่งต่อไปยัง AI Server จากนั้นโมเดล RT-DETR-L จะตรวจจับรอยโรค ได้ผลเป็นชื่อโรคและค่าความมั่นใจ เมื่อได้ชื่อโรคแล้ว ระบบ RAG จะดึงข้อมูลยาและวิธีรักษาที่เกี่ยวข้องจากคู่มือกรมการข้าว ส่งให้ Gemini 2.5 Flash ช่วยสรุปเป็นภาษาที่เข้าใจง่าย แล้วส่งผลลัพธ์กลับไปให้เกษตรกรในรูปแบบการ์ด Flex Message ทาง LINE ครับ"*

### สรุปผลการดำเนินงาน

#### สรุปผลตามกลุ่มผู้ใช้งาน :
* **1. ฝั่งเกษตรกร / ผู้ใช้งานทั่วไป :**
  * ใช้งานผ่าน Rich Menu 3 เมนู (ถ่ายภาพ, ส่งภาพ, วิธีใช้งาน)
  * ได้รับผลตรวจวินิจฉัยพร้อมการ์ด Flex Message สรุปชื่อโรค, สาเหตุ, อาการ, สารเคมี / ชีวภัณฑ์ และวิธีจัดการแปลง
  * พิมพ์สอบถามเพิ่มเติมได้ตลอดเวลา และเตือนให้ถ่ายใหม่เมื่อภาพไม่ชัด
* **2. ฝั่งผู้ดูแลระบบ (Admin) :**
  * ตรวจสอบประวัติการส่งภาพและสถิติผ่านระบบ Log
  * จัดการและอัปเดตเอกสารข้อมูลโรคข้าวใน Pinecone ให้เป็นปัจจุบัน
  * ตรวจสอบสถานะการทำงานของเซิร์ฟเวอร์
