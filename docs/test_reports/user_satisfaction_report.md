# รายงานผลการประเมินความพึงพอใจของผู้ใช้งานต่อระบบแชทบอท (User Satisfaction Evaluation Report)

- **โครงการ:** ระบบรู้จำและวินิจฉัยโรคใบข้าวด้วยปัญญาประดิษฐ์ผ่านแอปพลิเคชัน LINE (Rice Leaf Disease AI Assistant)
- **กลุ่มตัวอย่าง:** เกษตรกรผู้ปลูกข้าว, เจ้าหน้าที่ส่งเสริมการเกษตร, และผู้ใช้งานทั่วไป รวมจำนวน **30 ราย ($N=30$)**
- **เครื่องมือที่ใช้:** แบบประเมินมาตราส่วนประมาณค่า 5 ระดับ (5-Point Likert Scale) ครอบคลุม 5 มิติ
- **ระดับความพึงพอใจเฉลี่ยรวม (Overall Satisfaction):** **4.58 / 5.00 ($S.D. = 0.53$) ระดับ "มากที่สุด"**

## 2. เกณฑ์การแปลผลคะแนนเฉลี่ย (Likert Scale Interpretation)

อ้างอิงตามเกณฑ์การประเมินมาตรฐานทางสถิติ:
- **4.51 – 5.00** : ระดับความพึงพอใจ **มากที่สุด**
- **3.51 – 4.50** : ระดับความพึงพอใจ **มาก**
- **2.51 – 3.50** : ระดับความพึงพอใจ **ปานกลาง**
- **1.51 – 2.50** : ระดับความพึงพอใจ **น้อย**
- **1.00 – 1.50** : ระดับความพึงพอใจ **น้อยที่สุด**

## 4. การวิเคราะห์และอภิปรายผลในแต่ละด้าน

1. **ด้านความสะดวกในการใช้งาน (คะแนนสูงสุด $\bar{X} = 4.67$):**
   - กลุ่มตัวอย่างกว่าร้อยละ 66.7 ซึ่งเป็นเกษตรกรที่มีอายุเกิน 40 ปี ระบุตรงกันว่าระบบใช้งานง่ายมาก เนื่องจากทุกคนมีแอปพลิเคชัน LINE ติดตั้งอยู่แล้วในโทรศัพท์ ไม่ต้องลงทะเบียนหรือเรียนรู้การติดตั้งโปรแกรมใหม่
   - แถบเมนูลัด (Rich Menu) 6 ช่องด้านล่าง ช่วยลดการพิมพ์ข้อความ เกษตรกรสามารถกดปุ่มขอวิธีใช้งาน หรือดูข้อมูลยาได้อย่างสะดวก

2. **ด้านความเร็วในการตอบกลับ ($\bar{X} = 4.63$):**
   - ด้วยสถาปัตยกรรมโมเดล **RT-DETR-L** ที่ประมวลผลแบบ Real-time Inference บน GPU ได้เร็วเพียง 6.8 มิลลิวินาที ทำให้เมื่อผู้ใช้ส่งรูปภาพไปใน LINE ระบบสามารถส่งภาพที่มี Bounding Box พร้อมข้อความยืนยันชื่อโรคกลับมาได้ภายใน 1-2 วินาที ซึ่งสร้างความประทับใจให้ผู้ทดสอบเป็นอย่างมาก

3. **ด้านประโยชน์และคุณภาพเนื้อหา ($\bar{X} = 4.57$):**
   - เกษตรกรและนักวิชาการเกษตรพึงพอใจที่ระบบระบุชื่อสารเคมีทางการค้า พร้อมสารออกฤทธิ์และ **"อัตราส่วนผสมต่อน้ำ 20 ลิตร"** อย่างชัดเจนตามฐานข้อมูลวิชาการของกรมการข้าว ทำให้สามารถนำไปหาซื้อที่ร้านเคมีเกษตรและผสมฉีดพ่นได้ทันทีโดยไม่เกิดอันตรายต่อต้นข้าว

4. **ด้านความแม่นยำในการตรวจจับ ($\bar{X} = 4.43$):**
   - อยู่ในระดับ **"มาก"** โดยผู้ทดสอบมองว่าในสภาพแสงแดดจ้าหรือถ่ายภาพใบข้าวจากระยะไกล อาจมีความมั่นใจลดลงบ้าง ซึ่งเป็นเรื่องปกติของแบบจำลองคอมพิวเตอร์วิทัศน์ อย่างไรก็ตาม กลุ่มตัวอย่างชื่นชมที่ระบบมี **Guardrail แนะนำให้ถ่ายภาพระยะใกล้ใหม่** แทนที่จะเดาโรคผิดพลาด

## 5. ข้อเสนอแนะเชิงคุณภาพจากผู้ใช้งาน (Qualitative Feedback)

จากการรวบรวมข้อคิดเห็นและข้อเสนอแนะเพิ่มเติมจากกลุ่มตัวอย่าง พบประเด็นสำคัญดังนี้:
* **จุดเด่นที่ชื่นชอบ:**
  - *"ไม่ต้องโหลดแอปเพิ่ม ใช้ใน LINE ที่คุ้นเคยอยู่แล้ว แค่ถ่ายรูปก็รู้โรคทันที"* (เกษตรกร จ.สุพรรณบุรี)
  - *"บอกอัตราผสมยาต่อน้ำ 20 ลิตรชัดเจนดีมาก ชาวบ้านเอาไปบอกร้านขายยาเกษตรได้เลย"* (เกษตรกร จ.พระนครศรีอยุธยา)
  - *"ระบบฉลาด ไม่มั่วเดาโรค ถ้ารูปมืดหรือเบลอจะบอกให้ถ่ายใหม่"* (เจ้าหน้าที่ส่งเสริมการเกษตร จ.ชัยนาท)
* **ข้อเสนอแนะสำหรับการต่อยอดในอนาคต:**
  - เพิ่มการตรวจวินิจฉัยกลุ่มแมลงศัตรูพืช เช่น เพลี้ยกระโดดสีน้ำตาล และหนอนกอข้าว
  - เพิ่มฟังก์ชันแจ้งเตือนสภาพอากาศและความเสี่ยงการระบาดของโรคในระดับตำบล
