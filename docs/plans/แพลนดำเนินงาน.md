# แพลนดำเนินงาน — Rice Disease LINE Chatbot (RT-DETR + RAG)
*อัปเดตล่าสุด: 08 ส.ค. 2569*


สถาปัตยกรรมระบบ:
  รูปภาพ → RT-DETR-L (Object Detection) → ระบุโรค
  ข้อความ → RAG (Gemini 2.5 Flash + Vector DB) → คำตอบวิชาการ
  ทั้งหมดเชื่อมผ่าน n8n Workflow → LINE Chatbot

ฮาร์ดแวร์เทรน: NVIDIA GeForce RTX 4090 (24GB VRAM)
ฮาร์ดแวร์ Deploy: NVIDIA Jetson AGX Orin (32GB)
