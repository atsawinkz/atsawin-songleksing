1.1 ความเป็นมาและความส าคัญของโครงงาน 
เนื่องมาจากยุคปัจจุบันภาคเกษตรกรรมได้หันมาประยุกต์ใช้เทคโนโลยีสารสนเทศในการ
บริหารจัดการแปลงนาเพิ่มมากขึ้น เพื่อให้เข้าถึงข้อมูลและการแก้ไขปัญหาที่รวดเร็วและแม่นย ายิ่งขึ้น 
ข้าวเป็นพืชเศรษฐกิจที่ส าคัญของประเทศไทยและเป็นอาชีพหลักของเกษตรกรจ านวนมาก แต่ปัญหา
ส าคัญที่เกษตรกรต้องเผชิญอยู่เสมอคือการระบาดของโรคข้าว ซึ่งหากวินิจฉัยโรคผิดพลาดหรือรักษา
ล่าช้า จะส่งผลกระทบโดยตรงต่อปริมาณผลผลิตและคุณภาพของข้าว ท าให้เกษตรกรเสียโอกาสทาง
รายได้และมีต้นทุนการผลิตที่สูงขึ้นจากการใช้สารเคมีที่ไม่ตรงจุด 
จากการศึกษาปัญหาของเกษตรกรในปัจจุบัน พบว่าเมื่อเกิดความผิดปกติขึ้นกับต้นข้าว 
เกษตรกรมักประสบปัญหาในการระบุชนิดของโรคด้วยตนเอง การขอค าปรึกษาจากผู้เชี่ยวชาญหรือ
เจ้าหน้าที่เกษตรอาจท าได้ยากเนื่องจากข้อจ ากัดด้านระยะทางและจ านวนเจ้าหน้าที่ที่ไม่เพียงพอต่อ
พื้นที่ ข้อมูลวิธีการรักษาที่น่าเชื่อถือมักอยู่ในรูปแบบเอกสารวิชาการหรือคู่มือเล่มหนา ซึ่งไม่สะดวก
ต่อการค้นหาและน ามาใช้งานจริงในพื้นที่นา ส่งผลให้กระบวนการตัดสินใจรักษาโรคข้าวเป็นไปอย่าง
ล่าช้าและขาดความแม่นย า 
ดังนั้นจากปัญหาดังกล่าวผู้พัฒนามีแนวคิดที่จะพัฒนาระบบแชทบอทวิเคราะห์โรคข้าว
อัตโนมัติ ในรูปแบบของแอปพลิเคชันผ่านแพลตฟอร์ม LINE ขึ้นมาเพื่อช่วยให้อ านวยความสะดวก
ให้แก่เกษตรกร โดยการน าเทคโนโลยีปัญญาประดิษฐ์ (AI) มาใช้ในการวิเคราะห์รูปภาพใบข้าวที่
ผิดปกติ และประยุกต์ใช้เทคโนโลยี RAG (Retrieval-Augmented Generation) ร่วมกับ Vector 
Database เพื่อดึงข้อมูลวิธีการรักษาจากฐานข้อมูลวิชาการที่เชื่อถือได้มาตอบค าถามเกษตรกรได้
ทันที ระบบนี้จะช่วยให้เกษตรกรทราบชนิดของโรคและวิธีแก้ไขได้โดยไม่จ าเป็นต้องรอเจ้าหน้าที่ 
สามารถประหยัดเวลาและลดความเสียหายของผลผลิตได้อย่างมีประสิทธิภาพ ตลอดจนช่วยให้ผู้ดูแล
ระบบสามารถวิเคราะห์ประวัติการระบาด (Log) เพื่อน าไปสู่การวางแผนป้องกันโรคเชิงรุกในฤดูกาล
ถัดไปได้อย่างมีประสิทธิภาพ

1.2 วัตถุประสงค์ของโครงงาน 
1.2.1 เพื่อพัฒนาระบบแชทบอทวิเคราะห์โรคข้าวอัตโนมัติผ่านแอปพลิเคชัน LINE 
1.2.2 เพื่อเพิ่มช่องทางการเข้าถึงข้อมูลการจัดการโรคข้าวให้กับเกษตรกร ให้สามารถแก้ไข
ปัญหาได้ทันท่วงที 
1.2.3 เพื่อประยุกต์ใช้เทคโนโลยี RAG (Retrieval-Augmented Generation) และ Vector 
Database ในการเพิ่มความแม่นย าของการให้ข้อมูลโรคและการรักษา 
 
1.3 ขอบเขตของโครงงาน 
ระบบแชทบอทวิเคราะห์โรคข้าว เป็นระบบที่พัฒนาขึ้นเพื่ออ านวยความสะดวกในการ
วินิจฉัยโรคเบื้องต้น โดยมีขอบเขตการท างานดังนี้ 
1.3.1 ขอบเขตด้านผู้ใช้งาน (User) 
(1) 
เกษตรกร/ผู้ใช้งานทั่วไป 
(1.1) สามารถส่งรูปภาพใบข้าวที่มีความผิดปกติเข้าสู่ห้องแชท LINE 
(1.2) สามารถรับผลการวิเคราะห์ชื่อโรค สาเหตุ และวิธีการรักษาเบื้องต้นได้ 
(1.3) สามารถสอบถามข้อมูลเพิ่มเติมเกี่ยวกับโรคข้าวผ่านการพิมพ์ข้อความ
ได้ 
(2) 
ผู้ดูแลระบบ (Admin) 
(2.1)    สามารถจัดการข้อมูลเอกสารความรู้ (Knowledge Base) ในฐานข้อมูล 
Vector ได้ 
(2.2) สามารถดูประวัติการใช้งาน (Log) ของระบบได้ 
1.3.2 ขอบเขตด้านระบบและการท างาน (System Function) 
(1) 
การวิเคราะห์รูปภาพ (Image Analysis): ระบบใช้โมเดล RT-DETR (Real-
Time DEtection TRansformer) ในการตรวจจับ (Detection) และจ าแนก (Classification) 
ลักษณะรอยโรคที่ปรากฏบนใบข้าว 
(2) 
ระบบค้นหาข้อมูล (RAG System): ระบบใช้เทคนิค Retrieval-Augmented 
Generation เชื่อมต่อกับ Vector Database เพื่อค้นหาข้อมูลยาและการรักษาจากเอกสารคู่มือ
วิชาการที่เชื่อถือได้ 
(3) 
ระบบสนทนา (Conversational Agent): ใช้ Large Language Model (LLM) 
ในการประมวลผลภาษาธรรมชาติและเรียบเรียงค าตอบให้เข้าใจง่ายส าหรับเกษตรกร
