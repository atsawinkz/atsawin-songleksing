# ภาคผนวก ก
## คู่มือการใช้งานระบบแชทบอทวิเคราะห์โรคข้าว

---

ส่วนของคู่มือการใช้งานระบบแชทบอทวิเคราะห์โรคข้าว แบ่งออกเป็น 2 ส่วน ประกอบด้วย
1. **ส่วนสำหรับผู้ใช้งานทั่วไป (เกษตรกร):** การใช้งานระบบแชทบอทผ่านแอปพลิเคชัน LINE Official Account
2. **ส่วนสำหรับผู้ดูแลระบบ (Admin):** การบริหารจัดการระบบเวิร์กโฟลว์อัตโนมัติ (n8n) และฐานข้อมูลความรู้เวกเตอร์ (Pinecone Vector Database)

---

### ก.1 ส่วนสำหรับผู้ใช้งานทั่วไป (เกษตรกร)

#### ก.1.1 การเพิ่มเพื่อนและเริ่มต้นใช้งานแชทบอท (Add Friend)
ผู้ใช้งานสามารถเริ่มต้นใช้งานระบบได้โดยการเพิ่มเพื่อนในแอปพลิเคชัน LINE ผ่าน 2 ช่องทาง ได้แก่:
1. การสแกนรหัสคิวอาร์ (QR Code) ประจำบัญชีทางการของแชทบอท
2. การค้นหาด้วย LINE ID (@บอทวินิจฉัยโรคข้าว)

เมื่อทำการเพิ่มเพื่อนสำเร็จและเข้าสู่ห้องแชท ระบบจะส่งข้อความต้อนรับอัตโนมัติ (Greeting Message) เพื่อแนะนำตัวและสรุปฟังก์ชันการทำงานเบื้องต้น พร้อมทั้งแสดงแถบเมนูด้านล่าง (Rich Menu) เพื่อให้ผู้ใช้เลือกเข้าถึงคำสั่งต่าง ๆ ได้ทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-1 การเพิ่มเพื่อนและข้อความต้อนรับเข้าสู่ระบบแชทบอท
(คำอธิบายรูป: ภาพหน้าจอแอปพลิเคชัน LINE ขณะเพิ่มเพื่อนสำเร็จ มีข้อความต้อนรับอัตโนมัติปรากฏขึ้น และมีแถบ Rich Menu แสดงอยู่ที่ด้านล่างของหน้าจอ)
```

#### ก.1.2 การใช้งานเมนูหลัก (Rich Menu)
แถบเมนูลัดที่ด้านล่างของหน้าจอห้องแชท (Rich Menu) ออกแบบมาเพื่อให้เกษตรกรสามารถกดใช้งานได้อย่างสะดวกรวดเร็ว โดยแบ่งออกเป็น 3 เมนูคำสั่งหลัก ได้แก่:
1. **ตรวจโรคข้าว:** เมนูแนะนำการส่งภาพถ่ายใบข้าวเพื่อให้ระบบทำการวิเคราะห์
2. **วิธีการใช้งาน:** เมนูแสดงคำแนะนำขั้นตอนการถ่ายภาพใบข้าวที่ถูกต้อง และตัวอย่างคำถามที่สามารถสอบถามบอทได้
3. **เกี่ยวกับระบบ / ข้อมูลอ้างอิง:** เมนูแสดงข้อมูลรายละเอียดของโครงงาน และแหล่งอ้างอิงองค์ความรู้จากกรมการข้าว กระทรวงเกษตรและสหกรณ์

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-2 หน้าจอเมนูหลัก (Rich Menu) ที่แถบด้านล่างของห้องแชท LINE
(คำอธิบายรูป: ภาพหน้าจอแสดงแถบ Rich Menu ด้านล่างของห้องแชท LINE ซึ่งประกอบด้วย 3 ปุ่มคำสั่ง: ตรวจโรคข้าว, วิธีการใช้งาน, และเกี่ยวกับระบบ)
```

#### ก.1.3 การส่งรูปภาพใบข้าวเพื่อตรวจวินิจฉัยโรค (Image Diagnosis)
เกษตรกรสามารถส่งภาพถ่ายใบข้าวที่มีอาการผิดปกติเพื่อตรวจวินิจฉัยได้ตามขั้นตอนดังนี้:
1. กดที่ไอคอน **"กล้องถ่ายรูป"** เพื่อถ่ายภาพใบข้าวจากแปลงนาโดยตรง หรือกดไอคอน **"รูปภาพ"** เพื่อเลือกภาพที่ถ่ายเก็บไว้ในคลังภาพ
2. **ข้อแนะนำในการถ่ายภาพ:**
   - ควรโฟกัสภาพถ่ายระยะใกล้ (Close-up) บริเวณรอยโรคบนแผ่นใบข้าว
   - จัดให้แผ่นใบข้าวอยู่กึ่งกลางภาพ และมีแสงสว่างเพียงพอ
   - หลีกเลี่ยงภาพถ่ายที่เบลอ มีการสั่นไหว หรือภาพมุมกว้างที่เห็นทั้งแปลงนา
3. กดปุ่ม **"ส่ง" (Send)** เพื่อส่งภาพเข้าสู่ห้องแชท
4. ระบบจะส่งข้อความแจ้งเตือนสถานะการประมวลผลให้ผู้ใช้ทราบว่าระบบกำลังวิเคราะห์ภาพ

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-3 การเลือกและส่งรูปภาพใบข้าวที่มีรอยโรคเข้าสู่ห้องแชท LINE
(คำอธิบายรูป: ภาพหน้าจอขณะผู้ใช้เลือกภาพถ่ายใบข้าวที่มีอาการของโรคจากอัลบั้มหรือกล้อง และกดส่งเข้ามาในห้องแชท)
```

#### ก.1.4 การรับผลการวินิจฉัยโรคและคำแนะนำการรักษา (Diagnosis & Advisory Result)
เมื่อระบบประมวลผลเสร็จสิ้น แชทบอทจะส่งข้อความตอบกลับในรูปแบบข้อความตัวหนังสือที่มีโครงสร้างชัดเจน อ่านง่าย ประกอบด้วยข้อมูล 3 ส่วนสำคัญ:
1. **ผลการวินิจฉัยโรค:** แสดงชื่อโรคข้าวที่ตรวจพบ (ทั้งภาษาไทยและภาษาอังกฤษ เช่น โรคไหม้ข้าว / Rice Blast) พร้อมระบุระดับความเชื่อมั่นของโมเดล (Confidence Score คิดเป็นเปอร์เซ็นต์)
2. **สาเหตุและลักษณะอาการ:** อธิบายสาเหตุของโรค (เชื้อราหรือแบคทีเรีย) และลักษณะแผลที่สังเกตได้บนใบ
3. **แนวทางการจัดการและรักษา:** คำแนะนำการปฏิบัติตามหลักวิชาการของกรมการข้าว เช่น การควบคุมระดับน้ำในนา, การงดใส่ปุ๋ยไนโตรเจนชั่วคราว, ชนิดของสารชีวภัณฑ์หรือสารเคมีที่แนะนำ พร้อมอัตราการผสมฉีดพ่นที่ถูกต้องและปลอดภัย

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-4 ผลการวินิจฉัยโรคข้าวและคำแนะนำการรักษาที่บอทส่งตอบกลับผู้ใช้
(คำอธิบายรูป: ภาพหน้าจอข้อความผลลัพธ์ที่แชทบอทส่งกลับมา แสดงชื่อโรค ค่าความเชื่อมั่น สาเหตุของโรค และวิธีการรักษาจากคู่มือกรมการข้าว)
```

#### ก.1.5 การพิมพ์ข้อความสอบถามข้อมูลโรคข้าวเพิ่มเติม (Text Query / Conversational Q&A)
นอกจากการส่งภาพแล้ว ผู้ใช้งานสามารถพิมพ์ข้อความสอบถามข้อสงสัยเกี่ยวกับโรคข้าว การดูแลรักษา หรือการใช้ยาได้โดยตรง เช่น:
- *"โรคขอบใบแห้งเกิดจากอะไร"*
- *"ถ้าข้าวเป็นโรคไหม้ต้องใช้ยาตัวไหนฉีด"*
- *"โรคใบจุดสีน้ำตาลป้องกันยังไง"*

ระบบสืบค้นข้อมูลความรู้ (RAG) จะค้นหาข้อมูลที่ตรงจุดจากฐานข้อมูลวิชาการของกรมการข้าว และใช้ปัญญาประดิษฐ์เรียบเรียงคำตอบเป็นภาษาธรรมชาติที่กระชับและเข้าใจง่ายตอบกลับผู้ใช้ทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-5 การพิมพ์ข้อความสอบถามข้อมูลโรคข้าวและคำตอบจากระบบ
(คำอธิบายรูป: ภาพหน้าจอการสนทนาที่ผู้ใช้พิมพ์คำถามเกี่ยวกับโรคข้าวหรือการใช้ยา และแชทบอทตอบกลับด้วยคำแนะนำที่ถูกต้องตามหลักวิชาการ)
```

#### ก.1.6 การแจ้งเตือนกรณีภาพถ่ายไม่ชัดเจนหรืออยู่นอกขอบเขต (Fallback & Guardrails)
ระบบมีกลไกป้องกันความผิดพลาดเพื่อความปลอดภัยของเกษตรกร ดังนี้:
1. **กรณีส่งภาพที่ไม่ใช่ใบข้าว หรือภาพที่ตรวจไม่พบรอยโรค:** ระบบจะตอบกลับอย่างสุภาพว่า *"ระบบตรวจไม่พบรอยโรคข้าวในภาพ กรุณาถ่ายภาพใบข้าวที่มีรอยโรคให้ชัดเจนในระยะใกล้และส่งใหม่อีกครั้ง"*
2. **กรณีพิมพ์คำถามที่ไม่เกี่ยวข้องกับโรคข้าว:** เช่น ถามสภาพอากาศ ราคาทองคำ หรือถามเรื่องพืชชนิดอื่น ระบบ Guardrail จะตอบปฏิเสธอย่างสุภาพว่า ระบบนี้เป็น AI ผู้ช่วยวินิจฉัยและให้คำปรึกษาเฉพาะโรคข้าว จึงไม่สามารถตอบคำถามนอกขอบเขตได้

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |

+-------------------------------------------------------------------------+
ภาพที่ ก-6 การแจ้งเตือนกรณีส่งภาพที่ไม่ใช่ใบข้าวหรือคำถามนอกขอบเขต
(คำอธิบายรูป: ภาพหน้าจอแสดงข้อความปฏิเสธอย่างสุภาพของแชทบอทเมื่อผู้ใช้ส่งภาพวัตถุอื่นหรือพิมพ์คำถามที่ไม่เกี่ยวข้องกับเรื่องโรคข้าว)
```

### ก.2 ส่วนสำหรับผู้ดูแลระบบ (Admin)

#### ก.2.1 การเข้าสู่ระบบจัดการเวิร์กโฟลว์ (n8n Workflow Automation)
ผู้ดูแลระบบสามารถเข้าจัดการระบบควบคุมการทำงานอัตโนมัติได้ตามขั้นตอนดังนี้:
1. เปิดโปรแกรมเว็บเบราว์เซอร์ (เช่น Google Chrome) แล้วพิมพ์ URL ของระบบ n8n (เช่น `http://localhost:5678` หรือ URL ประจำเซิร์ฟเวอร์)
2. กรอก **Email** และ **Password** ของบัญชีผู้ดูแลระบบ
3. กดปุ่ม **"Sign in"** เพื่อเข้าสู่หน้าแดชบอร์ดหลักของ n8n

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-7 หน้าจอเข้าสู่ระบบ (Sign In) ของระบบ n8n Workflow Automation
(คำอธิบายรูป: ภาพหน้าจอ Login ของ n8n สำหรับให้ผู้ดูแลระบบกรอกอีเมลและรหัสผ่านเพื่อเข้าใช้งาน)
```

#### ก.2.2 การตรวจสอบผังการทำงานและการเชื่อมต่อระบบ (Workflow Canvas Overview)
เมื่อเข้าสู่ระบบ ผู้ดูแลระบบสามารถตรวจสอบและจัดการผังเวิร์กโฟลว์การทำงานของระบบแชทบอทได้ดังนี้:
1. เลือกเวิร์กโฟลว์โครงงาน **"Rice Leaf Disease Diagnosis Bot"**
2. หน้าจอจะแสดงผังการเชื่อมต่อโหนดต่าง ๆ (Canvas) ได้แก่:
   - **LINE Webhook Node:** จุดรับข้อมูลรูปภาพและข้อความจากแอปพลิเคชัน LINE
   - **Router Node:** โหนดคัดแยกประเภทข้อมูล (ภาพถ่าย หรือ ข้อความ)
   - **HTTP Request Node (Model API):** จุดเชื่อมต่อไปยัง AI Server เพื่อทำการตรวจจับโรคด้วย RT-DETR + MobileSAM
   - **Pinecone Vector Search Node:** โหนดสืบค้นข้อมูลคู่มือการรักษาโรคข้าวที่ตรงกับโรคที่ตรวจพบ
   - **Google Gemini 2.5 Flash Node:** โหนดประมวลผลภาษาเพื่อเรียบเรียงคำแนะนำ
   - **LINE Reply Node:** โหนดส่งข้อความตอบกลับไปยังผู้ใช้งานใน LINE
3. ตรวจสอบสถานะการเปิดใช้งานเวิร์กโฟลว์ โดยปุ่มสวิตช์มุมขวาบนต้องอยู่ในสถานะ **"Active"** เพื่อให้ระบบทำงานได้ตลอดเวลา

```
+-------------------------------------------------------------------------+

|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-8 ผังการทำงานภาพรวม (Workflow Canvas) บนระบบ n8n
(คำอธิบายรูป: ภาพหน้าจอผังการเชื่อมต่อโหนดต่าง ๆ บน n8n แสดงเส้นทางการรับส่งข้อมูลตั้งแต่ Webhook จนถึงการส่งข้อความตอบกลับ)
```

#### ก.2.3 การตรวจสอบประวัติการทำงานและข้อผิดพลาด (Execution Logs)
ผู้ดูแลระบบสามารถตรวจสอบสถานะการทำงานย้อนหลังและการแก้ปัญหา (Debugging) ได้ดังนี้:
1. คลิกที่แถบเมนู **"Executions"** ทางแถบด้านซ้ายของหน้าจอ
2. ระบบจะแสดงตารางรายการประวัติการเรียกใช้งานทั้งหมด พร้อมแสดงสถานะการทำงาน (Success / Error), เวลาที่เริ่มต้นทำงาน (Start time), และระยะเวลาที่ใช้ในการประมวลผล (Duration)
3. เมื่อคลิกที่รายการใดรายการหนึ่ง หน้าจอจะแสดงรายละเอียดข้อมูลนำเข้าและส่งออก (Input / Output Payload) ของแต่ละโหนดอย่างละเอียด ทำให้ผู้ดูแลระบบสามารถตรวจสอบได้ทันทีว่าเกิดปัญหาที่ขั้นตอนใด

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-9 หน้าจอแสดงรายการประวัติการทำงาน (Execution Logs) บนระบบ n8n
(คำอธิบายรูป: ภาพหน้าจอแสดงประวัติการทำงานย้อนหลังในหน้า Executions และการคลิกดูรายละเอียด Payload ของแต่ละโหนด)
```

#### ก.2.4 การจัดการฐานข้อมูลความรู้เวกเตอร์ (Pinecone Vector Database)
ผู้ดูแลระบบสามารถตรวจสอบและจัดการดัชนีข้อมูลความรู้ (Vector Index) ได้ดังนี้:
1. เข้าสู่เว็บไซต์คอนโซลของ Pinecone (`https://app.pinecone.io`) และลงชื่อเข้าใช้
2. เลือกดูรายละเอียด Index ประจำโครงงาน เช่น `rice-disease-index`
3. ตรวจสอบข้อมูลสถิติที่สำคัญ:
   - **Total Vectors:** จำนวนชิ้นส่วนข้อความ (Vectors) ที่จัดเก็บอยู่ในระบบ
   - **Dimension:** มิติของเวกเตอร์ (เช่น 768 หรือ 1536 มิติ)
   - **Metric:** รูปแบบการวัดความคล้ายคลึงของข้อความ (Cosine Similarity)
   - **Usage / Latency:** กราฟแสดงความถี่ในการสืบค้นข้อมูลและเวลาที่ใช้ในการค้นหา

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-10 หน้าจอจัดการ Index บน Pinecone Vector Database Console
(คำอธิบายรูป: ภาพหน้าจอแดชบอร์ดบนเว็บไซต์ Pinecone แสดงสถานะ Index จำนวนเวกเตอร์ และมิติข้อมูลของฐานความรู้โรคข้าว)
```

#### ก.2.5 การอัปเดตและเพิ่มเอกสารความรู้โรคข้าว (Knowledge Ingestion Script)
กรณีที่มีข้อมูลโรคข้าวใหม่ สารเคมีชนิดใหม่ หรือต้องการอัปเดตคู่มือวิชาการของกรมการข้าว ผู้ดูแลระบบสามารถเพิ่มข้อมูลเข้าสู่ระบบได้ดังนี้:
1. นำไฟล์เอกสารคู่มือฉบับใหม่ (ไฟล์ .pdf หรือ .txt) ไปจัดเก็บไว้ในโฟลเดอร์คลังเอกสารของระบบ (`data/knowledge_base/`)
2. เปิดโปรแกรม Terminal หรือ Command Prompt ในเครื่องเซิร์ฟเวอร์
3. รันคำสั่งสคริปต์สำหรับการนำเข้าข้อมูลความรู้ เช่น:
   ```bash
   python scripts/ingest_knowledge.py
   ```
4. สคริปต์จะทำการอ่านเอกสาร ตัดแบ่งข้อความออกเป็นส่วนย่อย (Chunking), คำนวณค่า Vector Embeddings ด้วยโมเดลภาษา และอัปโหลดเวกเตอร์ชุดใหม่เข้าสู่ Pinecone Index โดยอัตโนมัติ
5. เมื่อเสร็จสิ้น ระบบ RAG จะสามารถนำข้อมูลความรู้ใหม่มาใช้ตอบคำถามแก่เกษตรกรได้ทันทีโดยไม่ต้องทำการเทรนโมเดลใหม่

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-11 หน้าต่างการรันสคริปต์อัปเดตเอกสารความรู้โรคข้าวเข้าสู่ Vector Database
(คำอธิบายรูป: ภาพหน้าจอ Terminal ขณะรันสคริปต์ Ingestion แสดงขั้นตอนการอ่านไฟล์เอกสาร การทำ Chunking และการอัปโหลดเวกเตอร์ขึ้น Pinecone สำเร็จ)
```
