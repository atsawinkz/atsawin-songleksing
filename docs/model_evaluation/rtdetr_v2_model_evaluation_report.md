# รายงานผลการเทรนและการประเมินประสิทธิภาพโมเดล RT-DETR-L (Version 2 - Optimized Hyperparameters)
**โครงการ:** ระบบเชี่ยวชาญเพื่อการวินิจฉัยโรคพืชในข้าวและให้คำแนะนำด้วยปัญญาประดิษฐ์ (Rice Disease LINE Chatbot)  
**วันที่บันทึก:** 17 สิงหาคม 2569  
**โมเดลหลัก:** Real-Time Detection Transformer Large (RT-DETR-L v2)

---

## 1. บทสรุปผู้บริหาร (Executive Summary)

การปรับปรุงและเทรนซ้ำโมเดล **RT-DETR-L (Version 2)** สำหรับตรวจจับและระบุตำแหน่งโรคใบข้าว 5 ชนิด ได้ดำเนินการเสร็จสิ้นสมบูรณ์บนเครื่องประมวลผลประสิทธิภาพสูง (NVIDIA GeForce RTX 4090) โดยโมเดลผ่านการเรียนรู้รวม 88 Epochs (หยุดทำงานด้วยระบบ Early Stopping ที่ Epoch 88 และเลือกรอบค่าน้ำหนักที่ดีที่สุดใน **Epoch 63**) ใช้เวลาเทรนรวมทั้งสิ้น 2.607 ชั่วโมง

จากการทดสอบกับชุดข้อมูล **Test Set (354 รูปที่ไม่เคยเห็นมาก่อน)** โมเดลเวอร์ชัน 2 แสดงให้เห็นถึงการพัฒนาด้านความถูกต้องแม่นยำ (Precision) ที่สูงขึ้นอย่างมีนัยสำคัญ:
- **Precision ภาพรวมเพิ่มขึ้นเป็น 58.5%** (จากเดิม 56.5% ใน v1) ช่วยลดอัตราการแจ้งเตือนผิดพลาด (False Positive)
- **โรคใบไหม้ (Leaf Blast):** ประสิทธิภาพพัฒนาแบบก้าวกระโดด mAP50 เพิ่มขึ้นเป็น **81.8%** (+4.2%) พร้อม Precision สูงถึง **80.0%**
- **โรคกาบใบแห้ง (Sheath Blight):** mAP50 เพิ่มขึ้นเป็น **75.8%** (+1.3%) โดยมี Precision พุ่งสูงขึ้นจาก 65.3% เป็น **74.2% (+8.9%)**
- **โรคใบจุดสีน้ำตาล (Brown Spot):** รักษามาตรฐานความแม่นยำระดับสูงมากที่ **79.2% mAP50** และ Precision **72.3%**
- โมเดลถูกทำการส่งออก (Export) เป็นไฟล์มาตรฐาน **ONNX (FP16)** ขนาด 62.9 MB เรียบร้อยแล้ว พร้อมสำหรับการประมวลผลแบบ Real-Time (Inference Time 4.8 ms ต่อภาพ)

## 2. สภาพแวดล้อมและโครงสร้างการเทรน (Training Environment & Config)

### 2.1 สเปคฮาร์ดแวร์ที่ใช้เทรน (Training Hardware)

- **CPU:** Intel Core i9-14900K (32 Threads)

### 2.2 การตั้งค่า Hyperparameters (`train_rtdetr_v2.py`)
| Parameter | Value (v2) | เปรียบเทียบกับ v1 | คำอธิบายทางเทคนิค |
| :--- | :---: | :---: | :--- |
| `model` | `rtdetr-l.pt` | `rtdetr-l.pt` | Pre-trained RT-DETR-L จาก COCO Dataset |

| `batch` | `16` | `16` | Batch Size สำหรับ VRAM 24GB |

## 6. การวิเคราะห์เชิงลึกและอภิปรายผล (Deep Analysis & Discussion)

1. **Precision ที่เพิ่มขึ้นช่วยยกระดับระบบใช้งานจริง (Reduced False Alarms):**
   - การปรับใช้ Cosine Learning Rate และ Mixup ส่งผลให้โมเดลมีค่า **Precision สูงขึ้นชัดเจนใน 3 โรคหลัก (Leaf Blast 80.0%, Sheath Blight 74.2%, Brown Spot 72.3%)** ซึ่งช่วยลดการวินิจฉัยผิดพลาดเมื่อเกษตรกรส่งภาพใบข้าวเข้ามาทาง LINE Chatbot

2. **โรคใบไหม้ (Leaf Blast) ทะลุเกณฑ์ 80%:**
   - ได้รับคะแนน mAP50 สูงถึง **81.8%** เพิ่มขึ้นจากเดิม 4.2% แสดงว่าการทำ Data Augmentation แบบ Mosaic และ Cosine Annealing มีประสิทธิภาพสูงมากต่อรอยโรคทรงกระสวยที่มีขอบเขตชัดเจน

3. **การวิเคราะห์จุดคอขวดของโรคขอบใบแห้ง (Bacterial Leaf Blight):**
   - ผลการทดลองชี้ให้เห็นว่าการปรับปรุงเฉพาะระดับ Hyperparameters ไม่เพียงพอสำหรับการแก้ไขโรคขอบใบแห้ง เนื่องจากข้อจำกัดเชิงกายภาพของรอยโรคที่เป็นริ้วยาวแคบและปัญหา Label Noise ในชุดข้อมูลเดิม ซึ่งต้องใช้แนวทาง Data-Centric AI (Re-labeling) ตามที่เสนอไว้ในข้อเสนอแนะบทที่ 5

4. **ความเร็วการประมวลผล (Inference Speed):**
   - Pre-process: **0.3 ms**
   - Inference: **4.8 ms** (~208 FPS บน RTX 4090)
   - Post-process: **0.0 ms**
   - ความเร็วรวมต่ำกว่า 6 ms ต่อรูป เหมาะสมอย่างยิ่งกับการให้บริการผ่านแชทบอทแบบเรียลไทม์
