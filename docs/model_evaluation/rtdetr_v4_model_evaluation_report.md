# รายงานผลการเทรนและการประเมินประสิทธิภาพโมเดล RT-DETR-L (Version 4 - High-Resolution 800px & SOTA Optimization)
**โครงการ:** ระบบเชี่ยวชาญเพื่อการวินิจฉัยโรคพืชในข้าวและให้คำแนะนำด้วยปัญญาประดิษฐ์ (Rice Disease LINE Chatbot)  
**วันที่บันทึก:** 2 กันยายน 2569  
**โมเดลหลัก:** Real-Time Detection Transformer Large (RT-DETR-L v4)

---

## 1. บทสรุปผู้บริหาร (Executive Summary)

การปรับปรุงและเทรนซ้ำโมเดล **RT-DETR-L (Version 4)** ได้ดำเนินการเสร็จสิ้นสมบูรณ์บนเครื่องประมวลผลประสิทธิภาพสูง (NVIDIA GeForce RTX 4090) โดยโมเดลผ่านการเรียนรู้รวม 37 Epochs (หยุดทำงานด้วยระบบ Early Stopping ที่ Epoch 37 และเลือกรอบค่าน้ำหนักที่ดีที่สุดใน **Epoch 12**) ใช้เวลาเทรนรวมทั้งสิ้น **1.400 ชั่วโมง**

จากการทดสอบกับชุดข้อมูล **Test Set (354 รูปที่ไม่เคยเห็นมาก่อน / 742 Bounding Boxes)** โมเดลเวอร์ชัน 4 ประสบความสำเร็จอย่างสูงและ **สร้างสถิติคะแนนรวมสูงสุดใหม่ตลอดกาล (All-Time Project Record)**:
- **mAP@0.5 รวมทำสถิติสูงสุดที่ 60.5% (0.6048)** (สูงที่สุดนับตั้งแต่เริ่มทำโครงการ สูงกว่า v1 Baseline 59.3%, v2 58.3% และ v3 60.2%)
- **ความก้าวหน้าครั้งสำคัญของโรคใบขอบกาบแห้ง (Leaf Scald):** คะแนน mAP50 พุ่งขึ้นสู่ **55.0%** (+4.2% เมื่อเทียบกับ v3, +8.0% เมื่อเทียบกับ v2 และ +1.7% เมื่อเทียบกับ v1) พิสูจน์ว่าสมมติฐานการเพิ่มความละเอียดภาพเป็น 800px ช่วยให้ Transformer จับริ้วแผลแคบยาวได้ดีขึ้นจริง
- **สร้างสถิติสูงสุดใหม่ในโรคกาบใบแห้ง (Sheath Blight):** ทำคะแนนแตะ **76.6% mAP50** (สูงสุดในทุกเวอร์ชันที่เคยเทรนมา)
- **สร้างสถิติสูงสุดใหม่ในโรคใบจุดสีน้ำตาล (Brown Spot):** ทำคะแนนแตะ **80.8% mAP50** (สูงสุดในทุกเวอร์ชัน)
- **โรคใบไหม้ (Leaf Blast):** รักษามาตรฐานความแม่นยำสูงมากที่ **82.6% mAP50** (Precision 79.8%, Recall 76.5%)
- **ระบบแคชบนดิสก์ (`cache='disk'`):** แก้ปัญหา Linux OOM-Killer ได้ 100% โดยอ่านข้อมูลผ่าน NVMe SSD 2TB อย่างรวดเร็ว แคชเสร็จสิ้นใน 1.3 วินาที และใช้ RAM ปกติเพียง 6–8 GB
- **ความพร้อมใช้งานจริง:** โมเดลถูกทำการส่งออก (Export) เป็นไฟล์มาตรฐาน **ONNX (FP16)** ขนาด 62.9 MB เรียบร้อยแล้ว พร้อมสำหรับการประมวลผลที่ความเร็ว **7.2 ms ต่อภาพ (~138 FPS)** บนฮาร์ดแวร์จริง

## 6. บทวิเคราะห์ทางเทคนิคและข้อค้นพบเชิงวิชาการ (Technical Insights)

1. **การพิสูจน์สมมติฐานความละเอียดสูงต่อรอยโรคแคบยาว (Multi-scale Spatial Resolution):**
   - โรคใบขอบกาบแห้ง (Leaf Scald) มีคะแนนพุ่งขึ้นสู่ **55.0% mAP50** ซึ่งสูงสุดในประวัติศาสตร์ของโปรเจกต์ แสดงให้เห็นอย่างชัดเจนว่าการเพิ่มความละเอียดภาพเป็น 800x800 ช่วยเพิ่มจำนวนพิกเซลให้กับรอยโรคริ้วยาว ทำให้เลเยอร์ Multi-scale Deformable Attention ใน Transformer แยกแยะขอบเขตแผลออกจากพื้นหลังใบข้าวได้แม่นยำยิ่งขึ้น
2. **ความสมดุลสูงสุดระหว่าง Precision และ Recall:**
   - เวอร์ชัน 4 มีค่า **Precision 58.1%** และ **Recall 61.3%** ซึ่งมีความสมดุลและเสถียรที่สุดในบรรดาทุกเวอร์ชัน โดยมีคะแนนระดับ >75% ถึง 3 โรคหลัก (Brown Spot 80.8%, Leaf Blast 82.6%, Sheath Blight 76.6%)
3. **ประสิทธิภาพของระบบแคชข้อมูลระดับฮาร์ดแวร์ (`cache='disk'`):**
   - การสตรีมไฟล์ไบนารีจาก NVMe SSD 2TB ผ่าน Dataloader 16 Workers ช่วยลดภาระการถอดรหัส JPEG ของ CPU ได้อย่างสมบูรณ์แบบ และตัดปัญหา Linux Kernel OOM-Killer ได้ 100%
4. **ข้อจำกัดของโรคขอบใบแห้ง (Bacterial Leaf Blight - BLB):**
   - แม้คะแนนจะขยับขึ้นเล็กน้อยเป็น 7.42% แต่ยังคงอยู่ในระดับต่ำ ซึ่งตอกย้ำข้อสรุปเชิงวิจัยว่าปัญหาของโรคนี้เกิดจาก **Label Noise ในชุดข้อมูลตั้งต้น** (การตีกรอบ Bounding Box กว้างเกินขอบเขตแผลจริง) ซึ่งจำเป็นต้องอาศัยการ Re-labeling ในงานวิจัยระยะถัดไป
