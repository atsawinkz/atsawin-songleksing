# รายงานผลการเทรนและการประเมินประสิทธิภาพโมเดล RT-DETR-L (Version 3 - Morphological Preservation & Fine-tuning)
**โครงการ:** ระบบเชี่ยวชาญเพื่อการวินิจฉัยโรคพืชในข้าวและให้คำแนะนำด้วยปัญญาประดิษฐ์ (Rice Disease LINE Chatbot)  
**วันที่บันทึก:** 25 สิงหาคม 2569  
**โมเดลหลัก:** Real-Time Detection Transformer Large (RT-DETR-L v3)

---

## 1. บทสรุปผู้บริหาร (Executive Summary)

การปรับปรุงและเทรนซ้ำโมเดล **RT-DETR-L (Version 3)** ได้ดำเนินการเสร็จสิ้นสมบูรณ์บนเครื่องประมวลผลประสิทธิภาพสูง (NVIDIA GeForce RTX 4090) โดยโมเดลผ่านการเรียนรู้รวม 66 Epochs (หยุดทำงานด้วยระบบ Early Stopping ที่ Epoch 66 และเลือกรอบค่าน้ำหนักที่ดีที่สุดใน **Epoch 41**) ใช้เวลาเทรนรวมทั้งสิ้น **1.946 ชั่วโมง**

จากการทดสอบกับชุดข้อมูล **Test Set (354 รูปที่ไม่เคยเห็นมาก่อน / 742 Bounding Boxes)** โมเดลเวอร์ชัน 3 ทำผลงานได้อย่างยอดเยี่ยมและ **สร้างสถิติคะแนนสูงสุดใหม่ (New All-time Record) ให้กับโครงการ**:
- **mAP@0.5 ภาพรวมทำสถิติสูงสุดที่ 60.2%** (ทะลุหลัก 60% ได้สำเร็จเป็นครั้งแรก สูงกว่า v1 Baseline 59.3% และ v2 58.3%)
- **อัตราการตรวจจับ (Recall) ภาพรวมสูงสุดที่ 61.9%** (จากเดิม 60.9% ใน v1 และ 60.5% ใน v2) ช่วยให้ระบบไม่พลาดการตรวจจับรอยโรคจริงในแปลงนา
- **โรคใบไหม้ (Leaf Blast) ทำผลงานก้าวกระโดด:** mAP50 พุ่งทะลุแตะ **86.9%** (+9.3% เมื่อเทียบกับ v1 และ +5.1% เมื่อเทียบกับ v2) โดยมีทั้ง Precision (80.6%) และ Recall (82.2%) เกิน 80% ทั้งคู่
- **การปิด Mosaic พิสูจน์สมมติฐานสำเร็จ:** โรคใบขอบกาบแห้ง (Leaf Scald) ฟื้นตัวจาก 47.0% ใน v2 กลับขึ้นมาเป็น **50.8% mAP50** พร้อมค่า Recall สูงสุดที่ **56.5%**
- **โรคใบจุดสีน้ำตาล (Brown Spot):** รักษามาตรฐานความแม่นยำสูงมากที่ **80.2% mAP50** (Recall 79.1%, Precision 70.9%)
- **โรคกาบใบแห้ง (Sheath Blight):** ทำคะแนนระดับยอดเยี่ยมคงที่ที่ **75.8% mAP50** (Recall 78.5%, Precision 70.4%)
- โมเดลถูกทำการส่งออก (Export) เป็นไฟล์มาตรฐาน **ONNX (FP16)** ขนาด 62.9 MB เรียบร้อยแล้ว พร้อมสำหรับการประมวลผลแบบ Real-Time ด้วยความเร็ว **4.8 ms ต่อภาพ (~208 FPS)**

## 6. บทวิเคราะห์ทางเทคนิคและข้อค้นพบเชิงวิชาการ

1. **ความสำเร็จของ Leaf Blast (86.9% mAP50):**
   - การผสานระหว่าง Best Weights เดิม + อัตราการเรียนรู้ระดับ Fine-tuning (`0.0002`) + Geometric Augmentation ทำให้สถาปัตยกรรม Transformer Attention สามารถสกัด Feature ของแผลรูปกระสวยได้อย่างแม่นยำและคมชัดที่สุด
2. **การฟื้นตัวของ Leaf Scald จากการปิด Mosaic:**
   - ในรอบ v2 การเปิด Mosaic บีบอัดแผลยาวแคบจนโมเดลสูญเสียรายละเอียดพิกเซล แต่เมื่อปิด Mosaic ใน v3 คะแนน mAP50 ดีดกลับขึ้นมาทันทีเป็น **50.8%** และทำค่า **Recall ได้สูงสุดถึง 56.5%**
3. **ข้อสรุปเชิง Data-Centric AI สำหรับโรคขอบใบแห้ง (BLB):**
   - การทดลองทั้ง 3 รอบพิสูจน์ให้เห็นอย่างชัดเจนว่า โรคขอบใบแห้ง (BLB) มีข้อจำกัดที่เกิดจาก Label Noise และความกว้างของ Bounding Box ในชุดข้อมูลตั้งต้น ซึ่งไม่สามารถแก้ไขได้ด้วยการจูน Hyperparameters เพียงอย่างเดียว แต่ต้องใช้แนวทาง Data-Centric AI (Re-labeling) ในงานวิจัยขั้นต่อไป
4. **ความพร้อมในการ Deploy สู่ระบบจริง (Production Readiness):**
   - โมเดล v3 มีความเร็วในการประมวลผล **4.8 ms ต่อภาพ** (~208 FPS) และผ่านการ Export เป็น **ONNX (FP16)** ขนาด 62.9 MB เรียบร้อยแล้ว พร้อมนำไปใช้เป็นโมเดลตัวหลัก (Champion Model) ในระบบ FastAPI และ LINE Chatbot
