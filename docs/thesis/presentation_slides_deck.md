## 🖥️ สไลด์ที่ 1: หน้าปกและภาพรวมงานวิจัย (Title & Overview)
* **หัวข้อ:** ระบบเชี่ยวชาญเพื่อการวินิจฉัยโรคพืชในข้าวและให้คำแนะนำด้วยปัญญาประดิษฐ์
* **สถาปัตยกรรมหลัก:** Real-Time Detection Transformer (RT-DETR-L) + Hybrid RAG + LINE Chatbot + NVIDIA Jetson AGX Orin
* **ปัญหาและที่มา (Problem Statement):**
  - เกษตรกรไทยสูญเสียผลผลิตข้าว 15–30% ต่อปีจากโรคพืชที่ไม่ได้รับการวินิจฉัยอย่างทันท่วงที
  - ปัญหาการใช้สารเคมีผิดประเภทและผิดอัตราส่วนจากข้อมูลที่ไม่น่าเชื่อถือในอินเทอร์เน็ต
* **เป้าหมาย:** สร้างระบบวินิจฉัยโรคข้าวจากภาพถ่ายแปลงนาแบบ Real-time แม่นยำสูง พร้อมให้คำปรึกษาวิธีรักษามาตรฐานกรมการข้าวตลอด 24 ชั่วโมง
* **🎙️ Script ผู้บรรยาย:**
  > *"สวัสดีครับอาจารย์ทุกท่าน วันนี้ผมขอเสนอวิทยานิพนธ์เรื่อง 'ระบบเชี่ยวชาญเพื่อการวินิจฉัยโรคพืชในข้าวและให้คำแนะนำด้วยปัญญาประดิษฐ์' ซึ่งเป็นการนำโมเดล Vision Transformer สายพันธุ์ล่าสุด คือ RT-DETR-L ผสานเข้ากับระบบ Hybrid RAG บนแอปพลิเคชัน LINE เพื่อช่วยเกษตรกรตรวจจับโรคและแนะนำการรักษาที่ถูกต้อง แม่นยำ และรวดเร็วครับ"*

## 🖥️ สไลด์ที่ 2: สถาปัตยกรรมระบบรวม (End-to-End System Architecture)
* **ผังการทำงานของระบบ (System Pipeline):**
  1. **User Layer:** เกษตรกรส่งภาพถ่ายใบข้าวหรือพิมพ์คำถามผ่าน **LINE Application**
  2. **Orchestration Layer:** **n8n Workflow** คัดกรอง Intent (รูปภาพ ➔ AI Vision, ข้อความ ➔ RAG)
  3. **Vision Layer:** **RT-DETR-L v5 (FastAPI)** วินิจฉัย 5 โรคข้าวสำคัญใน 6.8 มิลลิวินาที
  4. **Knowledge Layer:** **Hybrid RAG (Pinecone + Gemini + PyThaiNLP BM25)** ดึงวิธีรักษามาตรฐาน
  5. **Response Layer:** ส่งผลวินิจฉัยพร้อมกรอบ Bounding Box และคำแนะนำแบบ Flex Message
* **จุดเด่น:** ทำงานแบบ End-to-End เวลาตอบสนองรวมเพียง **1.68 วินาที**
* **🎙️ Script ผู้บรรยาย:**
  > *"ในส่วนของสถาปัตยกรรมระบบ เราออกแบบให้เกษตรกรใช้งานง่ายที่สุดผ่าน LINE โดยมี n8n ทำหน้าที่เป็นตัวกระจายงาน หากเป็นภาพถ่ายจะส่งเข้า RT-DETR v5 บน GPU เพื่อตรวจจับรอยโรค จากนั้นจะนำชื่อโรคส่งต่อไปยัง Hybrid RAG เพื่อดึงสารเคมีและอัตราการใช้ที่ถูกต้องจากฐานความรู้กรมการข้าว แล้วตอบกลับเป็นบัตรข้อความที่อ่านง่ายครับ"*

## 🖥️ สไลด์ที่ 3: ชุดข้อมูลและการปฏิวัติด้วย Data-Centric AI (Dataset & Refinement)
* **ชุดข้อมูลทดลอง:** ภาพถ่ายใบข้าว 3,829 ภาพ (Stratified Split: Train 70%, Val 20%, Test 10%)
* **ปัญหาคอขวดเดิม (Bottleneck):**
  - โรคขอบใบแห้ง (Bacterial Leaf Blight: BLB) คะแนนความแม่นยำต่ำผิดปกติ ($mAP@0.5 < 10\%$)
  - เกิดจาก **Annotation Fragmentation:** แผลยาวแผลเดียวถูกตีกรอบแตกย่อยเป็น 5,922 กล่อง
* **การแก้ไขด้วย Data-Centric AI:**
  - รวมกรอบรอยโรคต่อเนื่องตามสัณฐานวิทยาจริง (Continuous Morphological Bbox) เหลือ 1,863 กล่อง
* **ผลลัพธ์:** คะแนนโรคขอบใบแห้งพุ่งขึ้นจาก **7.42% ➔ `69.50%` (+62.1% !!)**
* **🎙️ Script ผู้บรรยาย:**
  > *"จุดเปลี่ยนสำคัญของงานวิจัยนี้คือการใช้กระบวนทัศน์ Data-Centric AI ครับ ในตอนแรกโรคขอบใบแห้งได้คะแนนต่ำมากเพียง 7.4% แม้เราจะพยายามจูนโมเดลอย่างไรก็ไม่ดีขึ้น เมื่อเราตรวจสอบลึกลงไปพบว่า Bounding Box ถูกตีแตกเป็นกล่องย่อยถึงเกือบ 6,000 กล่อง เมื่อเราแก้ไขรวมกล่องตามแผลจริง คะแนนพุ่งขึ้นทันทีถึง 62.1% พิสูจน์ว่าคุณภาพของข้อมูลคือหัวใจหลักครับ"*

## 🖥️ สไลด์ที่ 4: การเปรียบเทียบผลการทดลอง RT-DETR-L 5 เวอร์ชัน (Model Evolution)
* **ตารางสรุปผลการทดลองบน Test Set (354 ภาพ):**

| เวอร์ชันโมเดล (Model Versions) | แนวคิดการปรับปรุง | mAP@0.5 รวม | Precision | Recall | ข้อค้นพบสำคัญ |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **v1: Baseline** | COCO Transfer Learning (640px) | 59.3% | 56.5% | 60.9% | BLB ติดเพดานที่ 10.5% |
| **v2: Hyperparameter Tuning** | ปรับ Cosine LR, Warmup, AdamW | 58.3% | 58.5% | 60.5% | การจูน HP ไม่แก้ปัญหาแผลยาว |
| **v3: Morphological Augmentation** | ปิด Mosaic, เพิ่ม Scale/HSV | 60.2% | 57.7% | 61.9% | เริ่มเห็นขอบแผลคมชัดขึ้น |
| **v4: High-Resolution (800px)** | ขยายอินพุตเป็น 800x800 พิกเซล | 60.5% | 58.1% | 61.3% | แผลเล็กดีขึ้น แต่ BLB ยังจมที่ 7.4% |
| **v5: Data-Centric Champion** | **แก้ไข Bounding Box BLB ตามสัณฐานจริง** | **`70.6%`** | **`73.5%`** | **`70.2%`** | **ทะลุเพดานประวัติศาสตร์ (+10.1%)** |

* **🎙️ Script ผู้บรรยาย:**
  > *"จากตารางวิวัฒนาการ 5 เวอร์ชันนี้ จะเห็นได้ชัดเจนครับว่า ในเวอร์ชัน 1 ถึง 4 ซึ่งเป็นการปรับแต่งฝั่งตัวโมเดล (Model-Centric) คะแนนจะวนเวียนอยู่ที่ 58–60% เท่านั้น แต่เมื่อเราปรับคุณภาพข้อมูลในเวอร์ชัน 5 คะแนนรวมกระโดดข้ามเพดานขึ้นสู่ 70.6% โดยมีความแม่นยำรวมสูงถึง 73.5% และตรวจจับได้ครอบคลุม 70.2% ครับ"*

## 🖥️ สไลด์ที่ 5: ผลการทดลอง Ablation Study: การตัดพื้นหลังแปลงนา (Segmentation Study)
* **สมมติฐานการวิจัย:** การตัดฉากหลังแปลงนาออกเป็นสีดำ จะช่วยเพิ่มความแม่นยำในการตรวจจับจริงหรือไม่?
* **ความล้มเหลวของวิธีดั้งเดิม (SOD):** โมเดลตัดพื้นหลังทั่วไปลบภาพจนกลายเป็นจอดำถึง **43.8%** จากปัญหา Green-on-Green
* **แนวทางที่พัฒนาขึ้นใหม่:** ใช้ **MobileSAM + Enclosing Bbox + Safety Guardrail 2%** สำเร็จ **75.14%**
* **ผลการเทรนเปรียบเทียบ (Controlled Experiment บน Test Set):**
  - **ภาพรวม (mAP@0.5):** Segmented Model ได้ **`72.00%`** vs Champion v5 ได้ **`70.56%`** (+1.44%)
  - **ความกระชับของกล่อง (mAP@0.5:0.95):** ลดลงจาก 35.54% เหลือ **`34.99%` (-0.55%)**
* **🎙️ Script ผู้บรรยาย:**
  > *"หนึ่งในคำถามสำคัญของการวิจัยคือ การตัดพื้นหลังแปลงนาออกจะช่วยให้โมเดลเก่งขึ้นหรือไม่ เราจึงได้ทำ Ablation Study โดยนำ MobileSAM มาตัดพื้นหลังร่วมกับระบบ Safety Guardrail และพบว่าในภาพรวมคะแนน mAP50 สูงขึ้นเล็กน้อยจาก 70.56% เป็น 72.00% แต่เมื่อเจาะลึกรายโรค เรากลับพบข้อค้นพบที่น่าตกใจมากครับ"*
