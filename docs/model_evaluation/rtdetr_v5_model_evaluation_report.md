# รายงานผลการเทรนและการประเมินประสิทธิภาพโมเดล RT-DETR-L (Version 5 - Data-Centric AI Champion)
**โครงการ:** ระบบเชี่ยวชาญเพื่อการวินิจฉัยโรคพืชในข้าวและให้คำแนะนำด้วยปัญญาประดิษฐ์ (Rice Disease LINE Chatbot)  
**วันที่บันทึก:** 21 กันยายน 2569  
**โมเดลหลัก:** Real-Time Detection Transformer Large (RT-DETR-L v5 Data-Centric)  
**ชุดข้อมูลทดสอบ:** Test Set (354 รูปที่ไม่เคยเห็นมาก่อน / 576 Bounding Boxes ที่ผ่านการปรับปรุง Label คุณภาพสูง)

## 1. บทสรุปผู้บริหาร (Executive Summary)

การทดลอง **Version 5 (Data-Centric AI)** ดำเนินการเสร็จสิ้นสมบูรณ์บนเครื่องประมวลผลประสิทธิภาพสูง (NVIDIA GeForce RTX 4090) โดยเป็นการนำค่าน้ำหนักของ Champion Model v4 มาทำการ Fine-tune ต่อยอดบนชุดข้อมูลภาพที่ผ่านการแก้ Bounding Box ของโรคขอบใบแห้ง (Bacterial Leaf Blight) ให้เป็นไปตามสัณฐานวิทยาแผลจริง (ลดกล่องแตกย่อย 5,922 กล่อง เหลือกรอบรอยโรคต่อเนื่อง 1,863 กล่อง)

ผลการประเมินอย่างเป็นทางการบน **Test Set (354 รูปที่ไม่เคยผ่านการเทรน)** สร้างความก้าวหน้าครั้งสำคัญและทำลายสถิติเดิมของโครงการอย่างราบคาบ:
- **ทะลุเพดาน 70%: mAP@0.5 รวมทำสถิติสูงสุดใหม่ตลอดกาลที่ `70.6%` (0.7056)** (สูงกว่า v4 เดิมถึง **+10.1%** และสูงกว่า v1 Baseline ถึง **+11.3%**)
- **ปรากฏการณ์ก้าวกระโดดของโรคขอบใบแห้ง (Bacterial Leaf Blight):** คะแนน mAP50 พุ่งกระโดดจาก **7.42% ➔ `69.5%` (+62.1% !!)** โดยค่า Precision พุ่งขึ้นแตะ **78.7%** (+60.3%) และ Recall แตะ **75.3%** (+59.1%)
- **ความแม่นยำรวมสูงที่สุดในประวัติศาสตร์:** ค่าเฉลี่ย Precision รวมทุกโรคแตะ **`73.5%`** (+15.4% เมื่อเทียบกับ v4) และ Recall รวมแตะ **`70.2%`** (+8.9%)
- **ความกระชับของกล่องรอยโรค (mAP@0.5:0.95):** เพิ่มขึ้นเป็น **`35.5%`** (+6.1%) แสดงถึงความสามารถในการวางพิกัดกรอบรอยโรคได้แนบชิดตามขอบแผลจริงในระดับสูง
- **การส่งออกโมเดลและการนำไปใช้งาน:** Export เป็นไฟล์มาตรฐาน **ONNX (FP16)** ขนาด 62.9 MB สำเร็จสมบูรณ์ โดยมีความเร็วในการประมวลผลอยู่ที่ **6.8 ms ต่อภาพ (~147 FPS)** บน RTX 4090

## 4. ข้อค้นพบเชิงวิชาการที่สำคัญ (Academic Insights for Thesis)

1. **การพิสูจน์กระบวนทัศน์ Data-Centric AI เหนือ Model-Centric AI:**
   - ในการทดลองเวอร์ชัน 1 ถึง 4 คณะผู้วิจัยได้พยายามปรับเปลี่ยน Hyperparameters, Data Augmentation และเพิ่มขนาดความละเอียดภาพ (Model-Centric Approach) ซึ่งแม้จะช่วยให้ภาพรวมดีขึ้นแตะ 60.5% แต่โรค Bacterial Leaf Blight ยังคงติดเพดานคะแนนที่ประมาณ 7–10%
   - แต่เมื่อเปลี่ยนกระบวนทัศน์มาสู่ **Data-Centric AI** โดยการทำความสะอาดและปรับปรุงคุณภาพของ Bounding Box (Annotation Refinement) คะแนนของโรคขอบใบแห้งพุ่งสูงขึ้นทันทีถึง **+62.1%** และผลักดันให้คะแนนรวมของทั้งระบบทะลุสู่ **70.6%** ซึ่งเป็นหลักฐานเชิงประจักษ์ว่า **คุณภาพของข้อมูลคือตัวกำหนดเพดานความฉลาดของโมเดลอย่างแท้จริง**

2. **การขจัด False Positive และ False Negative ในโรคขอบใบแห้ง:**
   - ใน Confusion Matrix ฉบับใหม่ โมเดลสามารถจำแนกโรคขอบใบแห้งได้ถูกต้องถึง **70%** และมีอัตราการหลุดรอดไปเป็น Background เพียงเล็กน้อย สอดคล้องกับค่า Precision 78.7% และ Recall 75.3%

3. **การคัดเลือก Final Champion Model:**
   - คณะผู้วิจัยมีมติเอกฉันท์คัดเลือก **RT-DETR-L Version 5** เป็น **โมเดลตัวแทนหลักขั้นสุดท้าย (Final Champion Model)** สำหรับใช้ในระบบ LINE Chatbot และบรรจุลงในบทที่ 4 และ 5 ของเล่มปริญญานิพนธ์
