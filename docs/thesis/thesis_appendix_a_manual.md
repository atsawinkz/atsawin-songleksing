# ภาคผนวก ก
## คู่มือการใช้งานระบบแชทบอทวิเคราะห์โรคข้าว

---

คู่มือการใช้งานระบบแชทบอทวิเคราะห์โรคข้าว แบ่งออกเป็น 2 ส่วน ดังนี้
1. **ส่วนสำหรับผู้ใช้งานทั่วไป (เกษตรกร):** การใช้งานแชทบอทผ่านแอปพลิเคชัน LINE
2. **ส่วนสำหรับผู้ดูแลระบบ (Admin):** การจัดการระบบทำงานอัตโนมัติ (n8n) และฐานข้อมูลความรู้ (Pinecone)

---

### ก.1 ส่วนสำหรับเกษตรกรและผู้ใช้งานทั่วไป

#### ก.1.1 การเพิ่มเพื่อนและเริ่มต้นใช้งานแชทบอท
ผู้ใช้สามารถเริ่มต้นใช้งานได้ง่าย ๆ โดยการเพิ่มเพื่อนใน LINE ผ่าน 2 วิธี:
1. สแกนคิวอาร์โค้ด (QR Code) ของแชทบอท
2. ค้นหาด้วย LINE ID (@บอทวินิจฉัยโรคข้าว)

เมื่อกดเพิ่มเพื่อนและเปิดเข้าไปในห้องแชท แชทบอทจะส่งข้อความทักทายต้อนรับ แนะนำตัว และบอกวิธีใช้งานเบื้องต้น พร้อมกับแสดงเมนูหลักที่ด้านล่างของหน้าจอทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-1 การเพิ่มเพื่อนและข้อความต้อนรับของแชทบอท
(คำอธิบายรูป: หน้าจอ LINE ตอนกดเพิ่มเพื่อน และมีข้อความต้อนรับพร้อมเมนูด้านล่างปรากฏขึ้น)
```

---

#### ก.1.2 การใช้งานเมนูหลัก (Rich Menu)
ที่แถบด้านล่างของหน้าจอแชทจะมีเมนูลัดให้กดใช้งานได้สะดวก แบ่งออกเป็น 3 ปุ่มหลัก:
1. **ตรวจโรคข้าว:** แนะนำวิธีการส่งรูปถ่ายใบข้าวเพื่อให้บอทช่วยตรวจ
2. **วิธีการใช้งาน:** บอกขั้นตอนการถ่ายรูปใบข้าวให้ชัดเจน และตัวอย่างคำถามที่สามารถพิมพ์ถามบอทได้
3. **เกี่ยวกับระบบ:** แสดงข้อมูลเกี่ยวกับโครงงาน และหน่วยงานอ้างอิงข้อมูล (กรมการข้าว)

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-2 หน้าจอเมนูหลักด้านล่าง (Rich Menu)
(คำอธิบายรูป: หน้าจอ LINE แสดงปุ่มเมนูด้านล่าง 3 ปุ่ม ได้แก่ ตรวจโรคข้าว, วิธีการใช้งาน, และเกี่ยวกับระบบ)
```

---

#### ก.1.3 การส่งรูปภาพใบข้าวเพื่อตรวจโรค
เมื่อพบใบข้าวที่มีอาการผิดปกติในแปลงนา สามารถส่งรูปให้บอทตรวจได้ตามขั้นตอนนี้:
1. กดที่ไอคอน **"กล้องถ่ายรูป"** เพื่อถ่ายรูปใบข้าวในนาจริง หรือกดไอคอน **"รูปภาพ"** เพื่อเลือกรูปถ่ายที่มีอยู่ในเครื่อง
2. **คำแนะนำในการถ่ายรูป:**
   - ถ่ายรูปใบข้าวใกล้ ๆ (ระยะใกล้) ให้เห็นแผลหรือรอยโรคชัดเจน
   - ให้ใบข้าวอยู่ตรงกลางภาพ และถ่ายในที่ที่มีแสงสว่างพอดี
   - หลีกเลี่ยงภาพเบลอ ภาพสั่น หรือภาพมุมกว้างที่เห็นทั้งแปลงนา
3. กดปุ่ม **"ส่ง"** รูปภาพเข้าห้องแชท
4. บอทจะส่งข้อความแจ้งว่ากำลังวิเคราะห์รูปภาพ ให้รอสักครู่

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-3 การเลือกและส่งรูปภาพใบข้าวเข้าสู่ห้องแชท
(คำอธิบายรูป: หน้าจอ LINE ตอนเลือกรูปถ่ายใบข้าวที่มีอาการผิดปกติและกดส่งเข้าไปในแชท)
```

---

#### ก.1.4 การรับผลการตรวจและวิธีรักษาโรค
เมื่อบอทวิเคราะห์รูปภาพเสร็จแล้ว จะส่งข้อความบอกรายละเอียดกลับมา 3 ส่วน ดังนี้:
1. **ผลการตรวจวินิจฉัย:** บอกชื่อโรคข้าวที่ตรวจพบ (ทั้งภาษาไทยและภาษาอังกฤษ เช่น โรคไหม้ข้าว / Rice Blast) พร้อมบอกระดับความมั่นใจของระบบเป็นเปอร์เซ็นต์
2. **สาเหตุและอาการของโรค:** อธิบายว่าโรคเกิดจากเชื้อราหรือแบคทีเรีย และมีลักษณะแผลบนใบอย่างไร
3. **วิธีรักษาและการดูแล:** แนะนำวิธีจัดการแปลงนา และชนิดของยาหรือสารชีวภัณฑ์ที่แนะนำให้ใช้ พร้อมอัตราการผสมฉีดพ่นตามคู่มือของกรมการข้าว

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-4 ข้อความผลการวินิจฉัยโรคและคำแนะนำการรักษา
(คำอธิบายรูป: หน้าจอแสดงข้อความที่แชทบอทตอบกลับ บอกชื่อโรค เปอร์เซ็นต์ความมั่นใจ สาเหตุ และวิธีรักษา)
```

---

#### ก.1.5 การพิมพ์ข้อความสอบถามข้อมูลโรคข้าว
นอกจากส่งรูปภาพแล้ว ผู้ใช้ยังสามารถพิมพ์ข้อความถามข้อสงสัยเกี่ยวกับโรคข้าวหรือการดูแลรักษาได้เลย เช่น:
- *"โรคขอบใบแห้งเกิดจากอะไร"*
- *"ถ้าข้าวเป็นโรคไหม้ต้องใช้ยาตัวไหนฉีด"*
- *"โรคใบจุดสีน้ำตาลมีวิธีป้องกันยังไง"*

บอทจะค้นหาข้อมูลจากคู่มือวิชาการของกรมการข้าว แล้วสรุปคำตอบที่เข้าใจง่ายและตรงจุดส่งกลับมาให้ทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-5 การพิมพ์ข้อความสอบถามข้อมูลโรคข้าว
(คำอธิบายรูป: หน้าจอตอนพิมพ์ถามข้อสงสัยเรื่องโรคข้าว และบอทตอบคำแนะนำกลับมา)
```

---

#### ก.1.6 การแจ้งเตือนกรณีส่งรูปไม่ชัดเจนหรือถามนอกเรื่อง
ระบบมีการแจ้งเตือนเพื่อช่วยแนะนำผู้ใช้งานในกรณีต่าง ๆ ดังนี้:
1. **ถ้าส่งรูปอื่นที่ไม่ใช่ใบข้าว หรือภาพมองไม่เห็นรอยโรค:** บอทจะตอบว่า *"ตรวจไม่พบรอยโรคข้าวในภาพ กรุณาถ่ายภาพใบข้าวที่มีรอยโรคให้ชัดเจนในระยะใกล้แล้วส่งใหม่อีกครั้ง"*
2. **ถ้าพิมพ์ถามเรื่องอื่นที่ไม่เกี่ยวกับข้าว:** เช่น ถามสภาพอากาศ ราคาทอง หรือถามเรื่องพืชชนิดอื่น บอทจะแจ้งอย่างสุภาพว่า ระบบนี้เชี่ยวชาญเฉพาะเรื่องโรคข้าว จึงไม่สามารถตอบเรื่องอื่นได้

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-6 การแจ้งเตือนเมื่อส่งภาพที่ไม่ใช่ใบข้าวหรือถามนอกเรื่อง
(คำอธิบายรูป: หน้าจอแชทบอทตอบแจ้งเตือนเมื่อตรวจไม่พบโรคข้าว หรือพิมพ์ถามเรื่องที่ไม่เกี่ยวข้อง)
```

### ก.2 ส่วนสำหรับผู้ดูแลระบบ (Admin)

#### ก.2.1 การเข้าสู่ระบบจัดการ (n8n Login)
ผู้ดูแลระบบสามารถเข้าใช้งานระบบควบคุมการทำงานอัตโนมัติได้ดังนี้:
1. เปิดเว็บเบราว์เซอร์ (เช่น Google Chrome) แล้วพิมพ์ลิงก์ของระบบ n8n (เช่น `http://localhost:5678` หรือลิงก์ประจำเซิร์ฟเวอร์)
2. กรอก **Email** และ **Password** ของผู้ดูแลระบบ
3. กดปุ่ม **"Sign in"** เพื่อเข้าสู่หน้าแดชบอร์ด

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-7 หน้าจอเข้าสู่ระบบจัดการ (n8n Login)
(คำอธิบายรูป: หน้าจอเข้าสู่ระบบ n8n สำหรับกรอกอีเมลและรหัสผ่านของผู้ดูแลระบบ)
```

---

#### ก.2.2 การตรวจสอบผังการทำงานของระบบ (Workflow Canvas)
เมื่อเข้าสู่ระบบแล้ว ให้เลือกเวิร์กโฟลว์ **"Rice Leaf Disease Diagnosis Bot"** หน้าจอจะแสดงขั้นตอนการทำงานของระบบที่เชื่อมต่อกันเป็นผังงาน (Canvas) ได้แก่:
1. **โหนดรับข้อมูลจาก LINE (LINE Webhook):** ทำหน้าที่รับรูปภาพและข้อความที่ผู้ใช้ส่งเข้ามา
2. **โหนดแยกประเภท (Router):** คัดแยกว่าเป็นรูปภาพหรือข้อความ
3. **โหนดเรียกโมเดล AI (Model API):** ส่งรูปไปให้โมเดลตรวจจับโรคข้าว
4. **โหนดค้นหาข้อมูล (Pinecone Vector Search):** ค้นหาวิธีรักษาโรคข้าวจากฐานข้อมูล
5. **โหนดสร้างคำตอบ (Google Gemini):** เรียบเรียงคำแนะนำให้อ่านเข้าใจง่าย
6. **โหนดส่งข้อความตอบกลับ (LINE Reply):** ส่งผลลัพธ์กลับไปที่แชทของผู้ใช้
*(หมายเหตุ: ต้องตรวจดูสวิตช์มุมขวาบนให้เปิดเป็น **"Active"** เพื่อให้ระบบทำงานตลอดเวลา)*

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-8 หน้าจอผังการทำงานของแชทบอทบน n8n
(คำอธิบายรูป: หน้าจอแสดงโหนดการทำงานต่าง ๆ ของระบบแชทบอทที่เชื่อมต่อกันบน n8n)
```

#### ก.2.3 การดูประวัติการใช้งานและข้อผิดพลาด (Execution Logs)
ผู้ดูแลระบบสามารถตรวจสอบการทำงานย้อนหลังของบอทได้ดังนี้:
1. คลิกที่เมนู **"Executions"** ทางแถบด้านซ้าย
2. หน้าจอจะแสดงรายการที่เคยประมวลผลทั้งหมด พร้อมบอกเวลา สถานะว่าผ่านหรือไม่ (Success หรือ Error) และเวลาที่ใช้ไป
3. สามารถคลิกเข้าไปดูรายละเอียดของแต่ละรายการได้ว่า ผู้ใช้ส่งภาพหรือข้อความอะไรเข้ามา และแต่ละขั้นตอนประมวลผลได้ผลลัพธ์อย่างไร ช่วยให้ตรวจสอบและแก้ไขปัญหาได้ง่าย

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-9 หน้าจอแสดงประวัติการทำงาน (Executions) บน n8n
(คำอธิบายรูป: หน้าจอแสดงรายการประวัติการใช้งานย้อนหลัง และการกดดูข้อมูลในแต่ละโหนด)
```

#### ก.2.4 การจัดการฐานข้อมูลความรู้ (Pinecone Vector Database)
ผู้ดูแลระบบสามารถตรวจดูฐานข้อมูลความรู้โรคข้าวได้ตามขั้นตอนนี้:
1. เข้าไปที่เว็บไซด์ Pinecone (`https://app.pinecone.io`) และลงชื่อเข้าใช้
2. เลือกดู Index ประจำโครงงาน เช่น `rice-disease-index`
3. ดูข้อมูลสำคัญ เช่น:
   - **Total Vectors:** จำนวนชิ้นข้อมูลความรู้ที่เก็บไว้ในระบบ
   - **Dimension:** ขนาดมิติของเวกเตอร์ (เช่น 768 หรือ 1536)
   - **สถิติการใช้งาน:** กราฟแสดงจำนวนครั้งที่มีการค้นหาข้อมูลและความเร็วในการค้นหา

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-10 หน้าจอจัดการฐานข้อมูลความรู้บน Pinecone
(คำอธิบายรูป: หน้าจอแดชบอร์ด Pinecone แสดงข้อมูล Index และจำนวนข้อมูลที่จัดเก็บ)
```

#### ก.2.5 การอัปเดตข้อมูลความรู้โรคข้าวเพิ่มเติม
หากมีข้อมูลโรคข้าวใหม่ หรือมีคู่มือวิชาการฉบับใหม่จากกรมการข้าว สามารถเพิ่มเข้าสู่ระบบได้ดังนี้:
1. นำไฟล์เอกสารฉบับใหม่ (ไฟล์ .pdf หรือ .txt) ไปวางไว้ในโฟลเดอร์ `data/knowledge_base/`
2. เปิดโปรแกรม Terminal หรือ Command Prompt
3. พิมพ์คำสั่งรันสคริปต์:
   ```bash
   python scripts/ingest_knowledge.py
   ```
4. ระบบจะอ่านเอกสาร ตัดแบ่งข้อความ และแปลงเป็นข้อมูลเวกเตอร์อัปโหลดเข้า Pinecone ให้โดยอัตโนมัติ ทำให้บอทสามารถนำข้อมูลใหม่ไปใช้ตอบคำถามผู้ใช้ได้ทันที

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       [ พื้นที่สำหรับวางรูปภาพ ]                         |
|                                                                         |
+-------------------------------------------------------------------------+
ภาพที่ ก-11 การรันคำสั่งอัปเดตข้อมูลความรู้โรคข้าว
(คำอธิบายรูป: หน้าต่าง Terminal ตอนรันคำสั่งเพิ่มข้อมูลคู่มือโรคข้าวเข้าสู่ฐานข้อมูล)
```
