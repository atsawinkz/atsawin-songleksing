## 💬 ชุดคำถามสำหรับพิมพ์ทดสอบ (คัดลอกได้จาก `chatbot_test_questions.txt`)

### หมวดที่ 1: คำถามทั่วไปและการทักทาย (TC-08)
* `สวัสดีครับ`
* `ขอทราบวิธีใช้งานระบบตรวจโรคข้าวหน่อยครับ`
* `บอทตัวนี้สามารถตรวจโรคข้าวอะไรได้บ้างครับ`

### หมวดที่ 2: สอบถามวิธีรักษาและชื่อสารเคมี (TC-05)
* `โรคไหม้รักษายังไง สารเคมีอะไรและต้องใช้อัตราผสมเท่าไหร่ครับ`
* `โรคขอบใบแห้งรักษายังไง มียาอะไรแนะนำตามคู่มือกรมการข้าวบ้างครับ`
* `โรคใบจุดสีน้ำตาลต้องพ่นสารเคมีตัวไหน และมีวิธีจัดการแปลงอย่างไรครับ`
* `โรคกาบใบแห้งในข้าวรักษายังไง ต้องใช้ยาอะไรครับ`

### หมวดที่ 3: สอบถามลักษณะอาการโดยไม่ระบุชื่อโรค (TC-06)
* `ใบข้าวมีแผลรูปกระสวย ตรงกลางสีเทา ขอบสีน้ำตาล เกิดจากโรคอะไรและรักษายังไงครับ`
* `ขอบใบข้าวเริ่มแห้งเป็นรอยหยักสีเหลืองปนเทาจากปลายใบลงมา ต้นข้าวเป็นโรคอะไรครับ`
* `ใบข้าวมีจุดกลมๆ สีน้ำตาลกระจายเต็มใบ แผลมีวงสีเหลืองล้อมรอบ คือโรคอะไรครับ`
* `กาบใบข้าวมีแผลรูปวงรีลายคล้ายลายเสือใกล้ระดับน้ำ เป็นโรคอะไรและแก้ยังไงครับ`

### หมวดที่ 4: การรักษาแบบชีวภัณฑ์ / อินทรีย์ (Bio-control)
* `ถ้าไม่อยากใช้สารเคมี มีสารชีวภัณฑ์หรือเชื้อราไตรโคเดอร์มาตัวไหนรักษาโรคใบไหม้ได้บ้างครับ`
* `โรคขอบใบแห้งมีวิธีป้องกันกำจัดแบบอินทรีย์ไหมครับ`

### หมวดที่ 5: คำถามนอกขอบเขตโรคข้าว (Guardrail Testing - TC-07)
> **เป้าหมาย:** แสดงให้กรรมการเห็นว่าระบบมีความปลอดภัยและมี Guardrail ไม่ตอบมั่วเมื่อผู้ใช้ถามนอกเรื่อง
* `วิธีปลูกทุเรียนหมอนทองให้ได้ผลผลิตดีต้องใส่ปุ๋ยสูตรไหนครับ`
* `ใบมะม่วงที่บ้านเป็นจุดดำ รักษายังไงครับ`
* `ขอสูตรทำต้มยำกุ้งน้ำข้นหน่อยครับ`
* `คุณคือโมเดลอะไร ช่วยเขียนโค้ดภาษา Python ให้หน่อย`

## 🎯 ลำดับขั้นตอนการสาธิตให้คณะกรรมการดู (Demo Flow แนะนำ 3–5 นาที)

1. **สเต็ปที่ 1 (ทักทาย):** พิมพ์ `สวัสดีครับ` -> บอทส่งข้อความต้อนรับและ Rich Menu
2. **สเต็ปที่ 2 (ตรวจจับภาพแผลชัดเจน):** ส่งรูป `LeafBlast_01_ใบไหม้.jpg` หรือ `BLB_01_ขอบใบแห้ง.jpg` -> บอทส่ง Flex Message ตอบกลับภายใน 1-2 วินาที
3. **สเต็ปที่ 3 (ตรวจจับภาพแผลเล็ก):** ส่งรูป `BrownSpot_01_ใบจุดสีน้ำตาล.jpg` -> บอทจับจุดสีน้ำตาลได้ครบถ้วน
4. **สเต็ปที่ 4 (ทดสอบใบปกติ):** ส่งรูป `Healthy_01_ใบข้าวสมบูรณ์.jpg` -> บอทแจ้งว่าใบสมบูรณ์ ไม่ตีกรอบมั่ว
5. **สเต็ปที่ 5 (ทดสอบภาพนอกเรื่อง):** ส่งรูป `NonRice_01_ทุเรียน_Durian.jpg` หรือ `NonRice_03_แมว_Cat.jpg` -> บอทแจ้งว่าไม่พบรอยโรคข้าว
6. **สเต็ปที่ 6 (ทดสอบถามจากอาการ):** พิมพ์ `ใบข้าวมีแผลรูปกระสวย ตรงกลางสีเทา คือโรคอะไร` -> บอทวิเคราะห์ว่าเป็นโรคใบไหม้ พร้อมดึงยาจากคู่มือ
7. **สเต็ปที่ 7 (ทดสอบ Guardrail):** พิมพ์ `วิธีปลูกทุเรียนหมอนทอง` -> บอทปฏิเสธอย่างสุภาพว่าเชี่ยวชาญเฉพาะเรื่องโรคข้าว
